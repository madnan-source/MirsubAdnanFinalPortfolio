# Mirsub Adnan – Portfolio Website

CS7026 Assignment 1. A five-page portfolio built with HTML5 and one external stylesheet.

| Page | Content |
| --- | --- |
| `index.html` | Homepage: hero, intro, section cards, about preview, call to action |
| `work.html` | 3D & VR: Lahore smog VR project, post-apocalyptic city, sci-fi spacecraft |
| `design.html` | Design & photography: OASIS magazine, "Wrong" album art, JamBestBuy product photos |
| `marketing.html` | UGC & marketing: video samples, content types, Streets & Fits, experience |
| `about.html` | Bio, education and skills tables, contact form |

All styling is in `style.css`. Images are in `images/`.
